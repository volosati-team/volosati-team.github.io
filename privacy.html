Privacy policy

Lisa Agent is a single-user personal assistant. This policy covers the Google user data it handles.

What is accessed

With the account holder's consent, the application requests OAuth scopes granting access to the account holder's own Gmail messages and Google Sheets spreadsheets. No other Google data is requested.

How it is used

Data is used solely to carry out tasks the account holder asks the assistant to perform, on the account holder's own account. It is not used for advertising, profiling, or any purpose the account holder did not request.

Storage and retention

OAuth credentials are stored locally on the account holder's own machine. Message and spreadsheet content is processed in memory or in local storage on that machine and is not retained beyond the task. No Google user data is stored on servers operated by any third party for this application.

Sharing

No Google user data is sold, rented, shared, transferred or disclosed to any third party. It is not used to train machine learning models and is not used for serving advertising. It is not made available to humans for review except where the account holder reads it themselves.

Revoking access

The account holder can revoke access at any time at myaccount.google.com/permissions; the application also deletes its stored credentials on request.

Contact

Use the user support address shown on the application's OAuth consent screen.
